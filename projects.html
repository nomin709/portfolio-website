Particle Physics · ML

Majorana Neutrino Hunt

Built a reproducible ML pipeline to classify particle interactions from detector waveform data collected by the Majorana Demonstrator experiment.

A DSC 180B capstone project analyzing waveform signals from high-purity germanium detectors to identify characteristics of particle interactions, packaged as a Dockerized pipeline for full reproducibility.

  • Problem: distinguish event types and estimate energy from raw detector waveforms.
  • Methods: time- and frequency-domain feature extraction, classification and regression models (scikit-learn, XGBoost, LightGBM), Docker-based reproducibility.
  • Outcome: generated energy spectrum visualizations and applied trained models to an unseen prediction dataset.

Data Analysis · Regression

Recipe Simplicity Analysis

Analyzed Food.com recipe data to find which recipe types need fewer steps, then built a model to predict step count from recipe features.

Explored over 80,000 recipes and 700,000+ user interactions to identify which recipe categories tend to be quickest to prepare, then framed step-count prediction as a regression problem.

  • Problem: find recipe types that are simpler and faster to prepare, and predict a recipe's number of steps.
  • Methods: data cleaning, hypothesis testing and permutation tests, missingness analysis, tuned Random Forest Regressor.
  • Outcome: cut test RMSE from 5.52 to 3.93 by adding tags and ratings as features and tuning hyperparameters.

Interactive Visualization

Hospital Stay Predictors

Built an interactive, scrollytelling site exploring which preoperative and demographic factors most affect how long patients stay in the hospital.

Using a Korean hospital dataset from VitalDB, this project surfaces the preoperative factors most linked to longer hospital stays and lets visitors filter patients and explore the effect of each variable.

  • Problem: identify which preoperative and demographic features most influence hospital stay length.
  • Methods: Random Tree Classifier for feature importance, D3.js and Chart.js scrollytelling visuals, an interactive filter tool.
  • Outcome: highlighted preoperative albumin and operation type as top predictors, with an interactive tool for exploring other variables.

Data Visualization · Mapping

Bikewatching

An immersive, interactive map visualization of bike traffic in the Boston area during different times of the day, with a time-of-day slider to filter trips.

A live station map that layers bike-share trip data over a Mapbox base map, letting visitors scrub through the day to see how traffic patterns shift at each station.

  • Problem: show how bike-share traffic flow changes throughout the day at a station level.
  • Methods: Mapbox GL for the base map, D3 for overlaying station markers, a time-of-day slider, and a color-coded departures/arrivals legend.
  • Outcome: an at-a-glance view of which stations accumulate or deplete bikes as the day progresses.
