Time Series Forecasting

Retail Demand Forecasting

Built a forecasting workflow for weekly product demand using feature engineering, rolling validation, and model comparison.

This project focuses on predicting weekly product demand and translating model output into inventory decisions. The workflow includes data cleaning, seasonal feature creation, lag variables, rolling validation, and error analysis by product category.

  • Problem: reduce stockouts and overstock by forecasting demand earlier.
  • Methods: lag features, rolling averages, train-test windows, baseline comparison.
  • Outcome: identified high-risk weeks and recommended reorder thresholds.
