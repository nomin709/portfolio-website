# Nomin Batjargal Portfolio - Work in Progress

A personal portfolio website for Nomin Batjargal, a data science graduate. The site highlights data science projects, contact links, and an embedded resume preview in a pixel solarpunk visual style.

## Pages

- `index.html` - Home page with intro, contact links, about text, and featured projects.
- `projects.html` - Three-column projects page with clickable project popup details.
- `resume.html` - Resume page with embedded Google Drive PDF preview, open/download controls, and collapse behavior.

## Tech

- Static HTML, CSS, and JavaScript
- No build step or framework required
- Responsive layout for desktop and mobile

## Run Locally

Open `index.html` directly in a browser, or use a local static server such as VS Code Live Server.
