# Personal Portfolio Website

The site highlights data science projects, contact links, and an embedded resume preview, built with a high-contrast, retro Neo-Brutalist design language and a terminal-inspired dark mode.

The portfolio is built using core web technologies, including vanilla HTML, CSS, and JavaScript, requiring no build steps, external libraries, or frameworks. The site utilizes dynamic DOM rendering fed by a localized `projects.json` file, which allows for streamlined content updates and easy maintenance.
